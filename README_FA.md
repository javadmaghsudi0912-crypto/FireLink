# FireLink

FireLink یک پروژه Android برای اشتراک سریع موقعیت حادثه بین اعضای یک گروه عملیاتی است.

## قابلیت‌های این نسخه
- ورود امن با Firebase Authentication
- گروه‌بندی اعضا
- ارسال مختصات GPS
- دریافت لحظه‌ای موقعیت‌های گروه
- کار با cache و صف آفلاین Firebase
- تأیید «دریافت شد»
- باز کردن مقصد در برنامه نقشه
- SMS پشتیبان از طریق برنامه پیامک خود گوشی
- Foreground Service برای حالت شیفت
- اعلان حادثه جدید
- Security Rules نمونه
- نصب و توزیع مستقیم با APK، بدون Play Store

## نکته مهم
این سورس برای تبدیل شدن به ابزار ایمنی عملیاتی باید ابتدا در محیط غیرعملیاتی تست، بازبینی و اعتبارسنجی شود.
برای استفاده بحرانی بهتر است نسخه بعدی شامل Push Notification مستقل، نقشه آفلاین، تست‌های خودکار و سیاست نگهداری داده باشد.
