# امنیت و حریم خصوصی

- دیتابیس عمومی نباشد.
- هر کاربر حساب جدا داشته باشد؛ رمز مشترک بین کل ایستگاه استفاده نشود.
- UID کاربران فقط به گروه‌های مجاز اضافه شود.
- در صورت گم‌شدن گوشی، حساب همان کاربر فوراً Disable شود.
- از قرار دادن رمز، keystore، یا local.properties در گروه‌های پیام‌رسان خودداری کنید.
- keystore را حداقل در دو محل آفلاین امن نگهداری کنید.
- نسخه‌های APK فقط از یک مسئول مشخص و با نام‌گذاری نسخه توزیع شوند.
- برای بررسی اصالت APK، SHA-256 فایل نسخه رسمی را همراه آن ثبت کنید.
- مختصات عملیات اطلاعات حساس محسوب می‌شود؛ نگهداری بلندمدت داده‌ها باید حداقلی باشد.
